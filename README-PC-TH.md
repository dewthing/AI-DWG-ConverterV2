# AI CAD Converter v6 — ชุด Windows PC

ชุดนี้ใช้สำหรับ Windows 10/11 แบบ 64-bit โปรแกรมทำงานในเครื่องของคุณและเปิดหน้า
UX/UI ผ่านเว็บเบราว์เซอร์ที่ `http://127.0.0.1:7860` ไฟล์ Drawing ไม่ถูกส่งไปยัง
บริการภายนอกโดยตัวโปรแกรม

## ติดตั้งครั้งแรก

1. แตกไฟล์ ZIP ทั้งหมดออกมาก่อน ห้ามเปิดโปรแกรมจากใน ZIP โดยตรง
2. ดับเบิลคลิก `SETUP_PC.bat`
3. รอให้ติดตั้ง Python packages และตรวจ Tesseract จนขึ้น `Setup complete`
4. ดับเบิลคลิก `START_PC.bat`
5. เบราว์เซอร์จะเปิดหน้า AI CAD Converter อัตโนมัติ

ต้องมี Python 3.10 ขึ้นไป หากยังไม่มี ให้ติดตั้ง Python 64-bit จาก
https://www.python.org/downloads/windows/ โดยเลือก `Add Python to PATH` แล้วรัน
`SETUP_PC.bat` อีกครั้ง

ตัวติดตั้งจะพยายามติดตั้ง Tesseract OCR ผ่าน Windows Package Manager และเพิ่มข้อมูล
ภาษาไทยจากโครงการทางการของ Tesseract หากติดตั้งอัตโนมัติไม่ได้ ให้ติดตั้ง Tesseract
เองแล้วรัน `SETUP_PC.bat` ซ้ำ โปรแกรมยังเปิดได้หากไม่มี Tesseract แต่จะยังสร้างข้อความ
OCR แบบแก้ไขไม่ได้

## วิธีใช้

1. เลือก PDF หรือรูปภาพ
2. เปิด `AI Auto mode` ไว้
3. เลือกภาษา OCR เป็น `tha+eng`
4. กดแปลงและตรวจ Preview
5. เมื่อพอใจ กดยืนยัน Preview แล้วดาวน์โหลดผลลัพธ์ ZIP
6. เปิด DXF ใน AutoCAD/GstarCAD และตรวจขนาด/เส้น/ข้อความก่อนนำไปใช้งานจริง

## DXF และ DWG

- DXF ถูกสร้างโดยตรงและแก้ไขวัตถุ LINE, CIRCLE, POLYLINE และ TEXT ได้
- DWG ต้องติดตั้ง ODA File Converter หรือเปิด DXF แล้ว Save As ด้วย AutoCAD/GstarCAD
- หากติดตั้ง ODA แล้ว ให้ติ๊ก `Also create DWG` และระบุไฟล์
  `ODAFileConverter.exe` ในหน้าโปรแกรม

## ตำแหน่งข้อมูล

- Python environment อยู่ใน `.venv`
- ข้อมูลช่วยรัน PC อยู่ใน `.runtime`
- feedback สำหรับการเรียนรู้อยู่ใน `data/feedback.jsonl`
- ผลลัพธ์แต่ละงานดาวน์โหลดจากหน้าโปรแกรมเป็น ZIP

อย่าลบโฟลเดอร์ `data` หากต้องการเก็บ feedback เพื่อให้ตัวจัดอันดับเรียนรู้ต่อเนื่อง

## แก้ปัญหาเบื้องต้น

- หน้าเว็บไม่เปิด: เปิด `http://127.0.0.1:7860` เอง และคงหน้าต่างสีดำไว้
- แจ้งว่า port 7860 ถูกใช้งาน: ปิดหน้าต่างโปรแกรมเก่าหรือรีสตาร์ตเครื่อง
- OCR ภาษาไทยไม่ทำงาน: รัน `SETUP_PC.bat` ซ้ำและตรวจว่าอินเทอร์เน็ตใช้งานได้
- ต้องการติดตั้ง dependencies ใหม่: ลบโฟลเดอร์ `.venv` แล้วรัน `SETUP_PC.bat` ใหม่
- ต้องการหยุดโปรแกรม: กลับไปที่หน้าต่างสีดำแล้วกด `Ctrl+C`

หมายเหตุ: คะแนน QA ใช้เลือกผลที่ใกล้ต้นฉบับที่สุด ไม่รับรองความถูกต้องทางวิศวกรรม
100% ควรตรวจมิติ, scale, line type และข้อความใน CAD ทุกครั้ง
